# Hockey IQ Simulator MVP v1.1

This package contains the original MVP v1.0 files and two v1.1 extensions:
- `ADDENDUM_SYSTEMES_PERSONNALISES_v1.1.md`: normative specification for coach-authored tactical systems, versioning, simulation, and team-private distribution.
- `CODEX_V1.1_INSTRUCTIONS.md`: supplementary prompt for Codex.

**Precedence:** v1.1 addendum > v1.0 specification and plan when conflicting. To start development, give Codex `CODEX_V1.1_INSTRUCTIONS.md` together with the full folder. The core v1.0 documents are preserved for traceability.
