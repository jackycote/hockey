# Hockey IQ Simulator — MVP M11–M18

Package de démarrage pour Codex.

## Documents
- `SPECIFICATION_TECHNIQUE.md` : exigences fonctionnelles, architecture, simulation, sécurité, API, données, critères d'acceptation.
- `PLAN_DEVELOPPEMENT.md` : phases, dépendances, livrables et tests.
- `CODEX_PROMPT.md` : instructions à donner à Codex.

## Démarrage
1. Fournir le dossier complet à Codex.
2. Soumettre `CODEX_PROMPT.md`.
3. Commencer par la phase 0 puis valider chaque jalon avant le suivant.

Les règles tactiques proposées sont des hypothèses configurables à valider par des entraîneurs qualifiés, non des prescriptions universelles.
